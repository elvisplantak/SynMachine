# Historical commit and branch maps

The original repository histories were prefixed with component paths and their
placeholder email corrected. Original review records keep their original IDs.
Use these tab-separated maps to find the imported equivalent:

- [UI commits](ui-commit-map.tsv)
- [Backend commits](backend-commit-map.tsv)
- [Firmware commits](firmware-commit-map.tsv)
- [All original and imported branch targets](ref-map.tsv)

The first column in each commit map is the original full ID, the second the new
full ID in this repository. Look up abbreviated IDs by their prefix. Each mapped
commit's component subtree is identical to its original repository tree. This
content equivalence preserves review traceability; it is not a new independent
acceptance of later changes. Historical absolute paths describe past environments.
